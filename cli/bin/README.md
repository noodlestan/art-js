# Artificial Bin

> Static entry point to parser, validator, compiler, bundler, watcher.

CLI that exposes all core pipeline commands.

This package is part of the [@artificials](../../README.md) toolkit.

## Development

Make sure you read the [@artificials README](../../README.md) first.

### Build

This package is meant for use in Node.js environments. The entry point is built using `esbuild` pre-configured by [Workspace Tooling](https://github.com/noodlestan/workspace-tooling).
